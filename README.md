# App del Asesor · 1001Carros (prototipo)

Prototipo navegable para un proyecto académico (USFQ) sobre la productividad de los asesores comerciales de 1001Carros.

- Funciona con **datos de prueba**: los asesores, los leads y las cédulas son inventados, y no se conecta con ningún sistema.
- Es HTML, CSS y JS estáticos dentro de `app/`. No hay que instalar nada.
- Los puntos, los plazos y los premios son provisionales y se cambian en `app/config.js`.
- Los datos de prueba están en `app/datos-prueba.js`.

Para verlo en la computadora, sirve la carpeta `app/` con cualquier servidor estático. En Vercel, `vercel.json` ya apunta a `app/`.
